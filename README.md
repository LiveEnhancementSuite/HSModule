## HSModule

HSModule is the Hammerspoon module behind Live Enhancement Suite for macOS. The source code now resides
in the main [LiveEnhancementSuite/LESforMacOS](https://github.com/LiveEnhancementSuite/LESforMacOS) repository
at [`extensions/les/`](https://github.com/LiveEnhancementSuite/LESforMacOS/tree/develop/extensions/les).

This repository exists for historical record, to see the historical source of this repo, please refer to
the [`archive-latest`](https://github.com/LiveEnhancementSuite/HSModule/tree/archive-latest) tag and for
the cleaned up history used for LESforMacOS re-releases, see the `v1.*.*` tags. For the history used in the first
release of v1.3.1, see the [`archive-v1.3.1`](https://github.com/LiveEnhancementSuite/HSModule/tree/archive-v1.3.1)
tag.
